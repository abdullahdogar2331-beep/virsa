# VIRSA

**Punjabi Cinema. One Home.**

VIRSA is a premium Android-first Punjabi cinema discovery app built with React Native + Expo Router.

## Current phase

This repository contains the first app foundation and a polished local UI prototype. Movie playback will use official YouTube videos supplied by rights holders/official channels; VIRSA does not download or re-host movie files.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npx expo start`.
4. Open the project in Expo Go or an Android emulator.

Expo Router uses file-based navigation. See the official Expo documentation for the current setup and SDK guidance.
